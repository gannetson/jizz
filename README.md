## What this means for you

- **Browsing the code?** Go to [birdr-app/birdr](https://github.com/birdr-app/birdr) — this copy is frozen and will fall behind.
- **Reporting a bug or requesting a feature?** Open it at [birdr-app/birdr/issues](https://github.com/birdr-app/birdr/issues). Issues opened here will not be picked up.
- **Have a clone of this repo?** Point it at the new remote:

  ```bash
  git remote set-url origin git@github.com:birdr-app/birdr.git
  ```

  Your existing commits and branches remain valid — the two repositories share
  the same history.

- **Have an open pull request here?** Push your branch to the new repository and
  reopen it there; the commits will apply cleanly.
